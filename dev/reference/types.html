EegFun.AnalysisInfo Type
julia
AnalysisInfo

Preprocessing and analysis metadata attached to EEG data containers.

Fields

  • reference::Symbol = :none: Reference scheme (:avg, :mastoid, :none, or channel label)

  • hp_filter::Float64 = 0.0: High-pass cutoff in Hz (0.0 if unfiltered)

  • lp_filter::Float64 = 0.0: Low-pass cutoff in Hz (0.0 if unfiltered)

  • sample_rate::Float64 = 0.0: Sample rate in Hz

  • n_ica_components_removed::Int = 0: Number of ICA components removed

  • n_channels_repaired::Int = 0: Number of channels repaired

  • repaired_channels::Vector{Symbol} = Symbol[]: Labels of repaired channels

source
EegFun.BaselineInfo Type
julia
BaselineInfo

Baseline correction parameters applied to time-frequency data (method and (start, stop) window in seconds).

Fields

  • method::Symbol: Baseline normalization method (:db, :percent, :relchange, :normchange, :zscore, or :absolute)

  • window::Tuple{Float64,Float64}: Baseline (start, stop) time window in seconds

source
EegFun.FilterInfo Type
julia
FilterInfo

Metadata and DSP filter object for a configured digital EEG filter.

Fields

  • filter_type::Symbol: :hp (highpass) or :lp (lowpass)

  • filter_object::Union{ZeroPoleGain,Vector{Float64}}: ZeroPoleGain for IIR or tap vector for FIR

  • filter_method::Symbol: :iir or :fir

  • cutoff_freq::Float64: Cutoff frequency in Hz

  • sample_rate::Float64: Sampling rate in Hz

  • order::Int: Filter order (for IIR filters)

  • n_taps::Union{Nothing,Int}: Tap count for FIR filters (nothing for IIR)

  • transition_band::Float64: Transition band width in Hz

EegFun.EpochCondition Type
julia
EpochCondition

Trigger-matching and timing rules defining an experimental condition for epoch extraction.

Fields

  • name::String: Condition name

  • trigger_sequences::Vector{Vector{Any}}: Trigger sequence(s) to match (integers, :any, ranges, or sets)

  • reference_index::Int = 1: 1-based position within the sequence aligned to t = 0

  • timing_pairs::Union{Nothing,Vector{Tuple{Int,Int}}} = nothing: Sequence index pairs constrained by min_interval/max_interval

  • min_interval::Union{Nothing,Float64} = nothing: Minimum inter-trigger interval in seconds

  • max_interval::Union{Nothing,Float64} = nothing: Maximum inter-trigger interval in seconds

  • mask_before_trigger::Union{Nothing,Int} = nothing: Only match sequences before this trigger code

  • mask_after_trigger::Union{Nothing,Int} = nothing: Only match sequences after this trigger code

  • mask_triggers::Union{Nothing,Vector{Int}} = nothing: Trigger codes defining search boundaries

  • mask_between_triggers::Union{Nothing,Vector{Tuple{Int,Int}}} = nothing: Trigger code pairs bounding valid search regions

source
EegFun.RideComponent Type
julia
RideComponent

Specification for a single RIDE component (:S, :C, :R, etc.).

Fields

  • name::Symbol: Component name (e.g. :S, :C, :R).

  • latencies::Union{Vector{Int}, Nothing}: Known trial sample latencies (centered around their median by ride_decompose), or nothing when latencies are estimated via woody_filter.

  • window_radius::Int: Woody-filter search radius in samples when latencies === nothing.

  • time_window::Union{Nothing, Tuple{Float64, Float64}}: Optional active component window (t_start, t_end).

source
EegFun.RideResult Type
julia
RideResult{T<:Real}

Decomposed RIDE templates (samples × channels × components), centered single-trial latencies, latency_offsets, residual tensor residue, convergence flag, and outer iteration count.

Fields

  • components::Vector{Symbol}: Ordered component names (e.g., [:s, :c, :r])

  • templates::Array{T,3}: Estimated component waveform templates (samples × channels × components)

  • latencies::Matrix{Int}: Centered single-trial latency shifts in samples (trials × components)

  • latency_offsets::Vector{Int}: Mean sample offset removed per component during centering

  • residue::Array{T,3}: Unexplained single-trial residual tensor (samples × channels × trials)

  • converged::Bool: true if outer alternating iteration met convergence tolerance

  • iterations::Int: Number of outer RIDE iterations executed

EegFun.IcaPrms Type
julia
IcaPrms

Algorithm hyperparameters for Infomax, Picard, and AMICA ICA decomposition.

Fields

  • l_rate::Float64 = 0.001: Initial Infomax learning rate

  • max_iter::Int = 512: Maximum optimization iterations for Infomax/Picard

  • w_change::Float64 = 1e-6: Weight-change convergence threshold

  • anneal_deg::Float64 = 60.0: Angle threshold (degrees) triggering learning-rate annealing

  • anneal_step::Float64 = 0.9: Multiplicative learning-rate annealing factor

  • blowup::Float64 = 1e15: Weight-norm divergence threshold

  • blowup_fac::Float64 = 0.8: Learning-rate reduction factor after blowup

  • max_weight::Float64 = 1e8: Maximum allowed weight magnitude

  • restart_factor::Float64 = 0.9: Learning-rate reduction factor on restart

  • degconst::Float64 = 180.0 / π: Radians-to-degrees conversion constant

  • default_stop::Float64 = 1e-6: Default gradient/step stopping tolerance

  • use_gpu::Bool = false: Enable GPU acceleration when available

  • picard_m::Int = 7: L-BFGS memory size for Picard

  • picard_lambda_min::Float64 = 0.01: Minimum Hessian eigenvalue regularization for Picard

  • picard_ls_tries::Int = 10: Maximum backtracking line-search attempts per Picard step

  • amica_lrate::Float64 = 0.1: Initial natural-gradient learning rate for AMICA

  • amica_max_iter::Int = 2000: Maximum EM/natural-gradient iterations for AMICA

  • amica_m::Int = 3: Number of generalized Gaussian mixture components per source in AMICA

EegFun.LmmStatsResult Type
julia
LmmStatsResult

Result of a mass-univariate linear mixed model fit across a channels × time grid (see fit_mass_lmm).

Fields

  • coefficients::Vector{String}: Fixed-effect names (e.g. "(Intercept)", "condition: B")

  • channels::Vector{Symbol}: Electrode labels

  • time_points::Vector{Float64}: Time points

  • beta::Array{Float64,3}: Fixed-effect estimates [channels × time × coefficients]

  • se::Array{Float64,3}: Standard errors [channels × time × coefficients]

  • z_values::Array{Float64,3}: Wald z-statistics (β̂ / SE) [channels × time × coefficients]

  • p_parametric::Array{Float64,3}: Uncorrected two-sided parametric p-values (t-distribution with Between-Within degrees of freedom; see inference.df_parametric)

  • p_corrected::Union{Array{Float64,3},Nothing}: Permutation FWER-corrected p-values (max-statistic, cluster-mass or TFCE, see inference.correction); NaN for untested coefficients; nothing without permutations

  • null_max::Matrix{Float64}: Null distribution of the maximum statistic [permutations × coefficients] (NaN columns for untested coefficients)

  • tested::Vector{Int}: Indices of the permutation-tested coefficients

  • singular_fits::Matrix{Bool}: Whether the fit at each [channel, time] point is singular

  • fit_status::Matrix{UInt8}: Fit outcome at each [channel, time] point, as an index into LMM_FIT_STATUS (LMM_FIT_STATUS[fit_status[c, t] + 1]):

    • 0 :converged: the optimizer met its tolerance.

    • 1 :roundoff_limited: the optimizer stopped at machine precision (the estimates are normally fine).

    • 2 :max_evals: the evaluation limit was reached before convergence; estimates are kept but unreliable.

    • 3 :optimizer_failure: any other optimizer failure; estimates are kept but unreliable.

    • 4 :flat_response: the data were constant or contained non-finite values; not fitted.

    • 5 :fit_error: the fit threw an error or produced non-finite estimates.

    Points with status 4 or 5 have NaN beta, se, z and p, and are excluded from the permutation null distribution and from cluster/TFCE formation.

  • inference::NamedTuple: Settings and auxiliary statistics used for inference (correction, n_perms, exhaustive, flip_by, n_blocks, cluster_threshold, tfce, spatial_connectivity, REML, contrasts, n_obs, formula, df_parametric, z_perm_obs)

  • epochs::Union{EpochData,Nothing}: The input epochs (EpochData method only; used for plotting)

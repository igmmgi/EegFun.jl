Data Container & Metadata Types ​

EegFun.AnalysisInfo Type
julia
AnalysisInfo

Preprocessing and analysis metadata attached to EEG data containers.

Fields

  • reference::Symbol = :none: Reference scheme (:avg, :mastoid, :none, or channel label)

  • hp_filter::Float64 = 0.0: High-pass cutoff in Hz (0.0 if unfiltered)

  • lp_filter::Float64 = 0.0: Low-pass cutoff in Hz (0.0 if unfiltered)

  • sample_rate::Float64 = 0.0: Sample rate in Hz

  • n_ica_components_removed::Int = 0: Number of ICA components removed

  • n_channels_repaired::Int = 0: Number of channels repaired

  • repaired_channels::Vector{Symbol} = Symbol[]: Labels of repaired channels

source
EegFun.BaselineInfo Type
julia
BaselineInfo

Baseline correction parameters applied to time-frequency data (method and (start, stop) window in seconds).

source
EegFun.FilterInfo Type
julia
FilterInfo

Metadata and DSP filter object for a configured digital EEG filter.

Fields

  • filter_type::Symbol: :hp (highpass) or :lp (lowpass)

  • filter_object::Union{ZeroPoleGain,Vector{Float64}}: ZeroPoleGain for IIR or tap vector for FIR

  • filter_method::Symbol: :iir or :fir

  • cutoff_freq::Float64: Cutoff frequency in Hz

  • sample_rate::Float64: Sampling rate in Hz

  • order::Int: Filter order (for IIR filters)

  • n_taps::Union{Nothing,Int}: Tap count for FIR filters (nothing for IIR)

  • transition_band::Float64: Transition band width in Hz

source

Epoch & RIDE Types ​

EegFun.EpochCondition Type
julia
EpochCondition

Trigger-matching and timing rules defining an experimental condition for epoch extraction.

Fields

  • name::String: Condition name

  • trigger_sequences::Vector{Vector{Any}}: Trigger sequence(s) to match (integers, :any, ranges, or sets)

  • reference_index::Int = 1: 1-based position within the sequence aligned to t = 0

  • timing_pairs::Union{Nothing,Vector{Tuple{Int,Int}}} = nothing: Sequence index pairs constrained by min_interval/max_interval

  • min_interval::Union{Nothing,Float64} = nothing: Minimum inter-trigger interval in seconds

  • max_interval::Union{Nothing,Float64} = nothing: Maximum inter-trigger interval in seconds

  • mask_before_trigger::Union{Nothing,Int} = nothing: Only match sequences before this trigger code

  • mask_after_trigger::Union{Nothing,Int} = nothing: Only match sequences after this trigger code

  • mask_triggers::Union{Nothing,Vector{Int}} = nothing: Trigger codes defining search boundaries

  • mask_between_triggers::Union{Nothing,Vector{Tuple{Int,Int}}} = nothing: Trigger code pairs bounding valid search regions

source
EegFun.RideComponent Type
julia
RideComponent

Specification for a single RIDE component (:S, :C, :R, etc.).

Fields

  • name::Symbol: Component name (e.g. :S, :C, :R).

  • latencies::Union{Vector{Int}, Nothing}: Known trial sample latencies (centered around their median by ride_decompose), or nothing when latencies are estimated via woody_filter.

  • window_radius::Int: Woody-filter search radius in samples when latencies === nothing.

  • time_window::Union{Nothing, Tuple{Float64, Float64}}: Optional active component window (t_start, t_end).

source
EegFun.RideResult Type
julia
RideResult{T<:Real}

Decomposed RIDE templates (samples × channels × components), centered single-trial latencies, latency_offsets, residual tensor residue, convergence flag, and outer iteration count.

source

  • is_sub_gaussian::Vector{Bool}: Sub-Gaussian component flags

julia
StatisticalData

Prepared ERP data for permutation or analytic statistical testing (prepare_stats).

Fields

  • data::Vector{ErpData}: Grand-average ERPs for conditions 1 and 2

  • analysis::AnalysisData: Design, 3D participant arrays [participants × electrodes × time], and analysis time points

  • se_cond1::Array{Float64,2}: Condition 1 standard error [electrodes × time]

source

EegFun.PermutationResult Type
julia
PermutationResult <: StatsResult

Cluster-based permutation test results on ERP data (permutation_test).

Fields

  • test_info::TestInfo: Test design, degrees of freedom, alpha, tail, and ClusterInfo

  • data::Vector{ErpData}: Grand-average ERPs for conditions 1 and 2

  • stat_matrix::StatMatrix: T-statistic matrix [electrodes × time]

  • masks::Masks: Significant positive and negative masks [electrodes × time]

  • clusters::Clusters: Detected positive and negative clusters

  • permutation_distribution::PermutationDistribution: Null distribution of maximum cluster statistics

  • electrodes::Vector{Symbol}: Electrode labels

  • time_points::Vector{Float64}: Analysis time points in seconds

  • critical_t::Union{Array{Float64,2},Tuple{Float64,Float64},Tuple{Array{Float64,2},Array{Float64,2}}}: Cluster-forming critical t-values

  • se::Array{Float64,2}: Mean-difference standard error over the analysis interval

  • se_cond1::Array{Float64,2}: Condition 1 standard error over the display interval

  • se_cond2::Array{Float64,2}: Condition 2 standard error over the display interval

  • se_diff::Array{Float64,2}: Mean-difference standard error over the display interval

Decoding & RSA Types ​

EegFun.DecodingParameters Type
julia
DecodingParameters

Cross-validation and multi-class coding parameters for MVPA/decoding.

Fields

  • chance_level::Float64: Theoretical chance accuracy (e.g., 0.5 for binary, 1 / n_classes for multi-class)

  • n_iterations::Int64: Number of cross-validation iterations

  • class_coding::Symbol: Multi-class coding scheme (:one_vs_one, :one_vs_all, :binary)

  • confusion_matrix::Union{Array{Float64,3},Nothing}: Confusion matrices [time × true_class × predicted_class]

  • raw_predictions::Union{Array{Float64,4},Nothing}: Raw predictions [iteration × fold × time × class]

source

EegFun.AutoRejectResult Type
julia
AutoRejectResult

Result of adaptive artifact rejection and channel repair (autoreject / autoreject!).

Fields

  • thresholds::Dict{Symbol,Float64}: Learned peak-to-peak amplitude threshold per channel (μV).

  • mode::Symbol: Rejection mode (:local or :global).

  • consensus_perc::Float64: Consensus rejection fraction κ (bad > κ * N rejects epoch).

  • max_repair_perc::Float64: Maximum repair fraction ρ (bad <= ρ * N interpolates all; middle band repairs worst ρ * N).

  • channels::Vector{Symbol}: Analyzed channels.

  • ptp::Matrix{Float64}: Peak-to-peak amplitude matrix (n_epochs × n_channels).

  • bad_matrix::BitMatrix: Channel × epoch threshold violations.

  • epochs_clean::Vector{Int}, epochs_repaired::Vector{Int}, epochs_rejected::Vector{Int}: Global epoch indices.

  • repaired_channels::OrderedDict{Int,Vector{Symbol}}, skipped_channels::OrderedDict{Int,Vector{Symbol}}: Per-epoch channel tracking.

  • rejection_info::Vector{EpochRejectionInfo}: Per-condition EpochRejectionInfo.

  • summary_table::DataFrame, channel_table::DataFrame: Summary and per-channel tables.

  • n_folds::Int, n_candidates::Int, seed::Union{Int,Nothing}, repair_method::Symbol: Run configuration.

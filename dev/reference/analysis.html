EegFun.autoreject! Method
julia
autoreject!(dat::AbstractVector{<:EpochData}; kwargs...) -> AutoRejectResult
autoreject!(dat::EpochData; kwargs...) -> AutoRejectResult

Adaptive cross-validated artifact rejection and channel repair (Jas et al., 2017), mutating dat in-place.

Keyword Arguments

  • mode::Symbol = :local: :local (per-channel CV thresholds + repair/reject) or :global (single global threshold, reject-only).

  • channel_selection = channels(): Channel selector.

  • interval_selection::Interval = times(): Time window for peak-to-peak evaluation.

  • n_folds::Int = 10, n_candidates::Int = 30, candidate_quantiles = (0.40, 1.0): CV search parameters.

  • consensus_perc::Real = 0.2, max_repair_perc::Real = 0.1: Consensus rejection (κ) and max repair (ρ) channel fractions.

  • repair_method::Symbol = :spherical_spline: :spherical_spline (m = 4, lambda = 1e-5) or :neighbor_interpolation.

  • seed::Union{Integer,Nothing} = 42, reject::Bool = true, verbose::Bool = true.

EegFun.jackknife_average Method
julia
jackknife_average(erps::AbstractVector{<:ErpData}; condition_selection = conditions(), pseudovalues::Bool = false)::Vector{ErpData}
jackknife_average(measurements::ErpMeasurementsResult; pseudovalues::Bool = true)::ErpMeasurementsResult
jackknife_average(file_pattern::String; input_dir = pwd(), participant_selection = participants(),
                  condition_selection = conditions(), output_dir = nothing, pseudovalues::Bool = false)

Create leave-one-out jackknife subaverages (or Smulders, 2010 pseudovalues) from ERP/LRP data.

For each participant i, computes the leave-one-out average X̄_{-i} of all other N - 1 participants (excluding i). This technique is standard for nonlinear ERP/LRP latency measures (e.g., fractional peak or fractional area onset latency) where single-participant waveforms have low signal-to-noise ratio.

Statistical Testing & Variance Correction

Because leave-one-out subaverages X̄_{-i} share N - 2 participants, their sample variance is compressed by (N - 1)^2 relative to single-participant variance:

  • Ulrich & Miller (2001) correction (pseudovalues = false): Divide t-statistics by N - 1 and F-statistics by (N - 1)^2.

  • Smulders (2010) pseudovalues (pseudovalues = true): Converts leave-one-out values X̄_{-i} into single-participant pseudovalues    , allowing standard t-tests, ANOVAs, correlations, and mixed-effects models without manual rescaling. For nonlinear measures (e.g., onset latency), extract measurements on pseudovalues = false subaverages first, then convert via jackknife_average(meas; pseudovalues = true).

References

  • Miller, J., Patterson, T., & Ulrich, R. (1998). Jackknife-based method for measuring LRP onset latency differences. Psychophysiology, 35(1), 99-115.

  • Ulrich, R., & Miller, J. (2001). Using the jackknife-based scoring method for measuring LRP onset effects in factorial designs. Psychophysiology, 38(5), 816-827.

  • Smulders, F. T. Y. (2010). Simplifying jackknifing of ERPs and getting more out of it. Psychophysiology, 47(2), 387-392.

EDA — Eccrine Sweat Gland Biophysics & SCR Measures Demo ​

Interactive Electrodermal Activity (EDA) simulator illustrating eccrine sweat gland innervation, Edelberg's (1993) poral valve model, parallel skin conductance (  ), and standard event-related Skin Conductance Response (ER-SCR) measures.

What it shows ​

  • Edelberg's Poral Valve Model: How sympathetic cholinergic bursts fill eccrine sweat ducts, raising intraductal pressure until pores open and skin conductance surges.

  • Conductance () vs. Resistance (): Why parallel sweat glands sum linearly in conductance ( ) while equal resistance drops correspond to vastly different sympathetic responses depending on baseline SCL.

  • Standard ER-SCR Morphology (Dawson et al., 2007): Live measurement markers for Latency (), Rise Time (), SCR Amplitude (), and 50% Half-Recovery Time () ().

Code ​

julia
using EegFun
using GLMakie

EegFun.signal_example_eda_scr()
